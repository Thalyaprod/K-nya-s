# Kenya Claude

Dossier principal.

- `cultur/` — sous-dossier culture

## Mettre ce dossier dans iCloud Drive

Sur Mac : copier le dossier `Kenya Claude` dans **Finder → iCloud Drive**
(chemin : `~/Library/Mobile Documents/com~apple~CloudDocs/`).

Sur iPhone / iPad : app **Fichiers → iCloud Drive → Nouveau dossier**,
nommer `Kenya Claude`, puis créer `cultur` à l'intérieur.
